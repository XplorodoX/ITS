01 — Motivation

Warum eigene Hardware statt Kahoot?

AALeC-V3 ist da — aber ungenutzt
Die Hochschule besitzt die Hardware bereits. Es fehlte eine vollständige Multiplayer-Anwendung dafür.

Smartphones stören, Controller konzentrieren
Kahoot zieht jeder sein Handy raus — Akku leer, WhatsApp offen, Ablenkung garantiert. Eigene Controller: Eingabe fertig, Handy bleibt weg.

Fragetypen die kein Touchscreen kann
Poti-Schätzfrage, Temperaturmessung, Drehgeber-Eingabe — physische Sensoren als Spielmechanik, nicht nur als Buzzerklon.

02 — Herausforderungen

Probleme & Lösungen

01
Echtzeit-Synchronisation aller Controller
Problem: Mehrere ESP8266-Geräte müssen exakt denselben Spielzustand anzeigen — ohne zentrale Taktung
Lösung: Zentraler State-Machine im Backend publiziert auf quiz/state — Controller reagieren rein event-getrieben via MQTT, kein Polling
02
Namenseingabe ohne Tastatur
Problem: Spieler müssen sich benennen können — das Gerät hat nur Drehgeber, Knopf und ein 128×64-Display
Lösung: Scroll-Liste per Encoder, Bestätigung per Klick — Backend verteilt die Namensliste per MQTT an alle Controller
03
Verbindungsabbrüche mitten im Spiel
Problem: WLAN bricht kurz ab — Controller verliert Spielzustand und hängt im falschen Screen
Lösung: Reconnect-Loop mit automatischem Re-Subscribe und erneutem quiz/connect — letzter State wird nach Reconnect neu publiziert

09 — Installation

Firmware flashen in 2 Schritten

1
Neueste firmware.bin von GitHub Releases laden
github.com/XplorodoX/ITS → Releases → firmware.bin herunterladen
2
Firmware flashen — Controller per USB verbinden, dann:
Linux / macOS
# esptool installieren (einmalig) pip install esptool # Flashen esptool.py --port /dev/ttyUSB0 \ --baud 921600 write_flash \ 0x0 firmware.bin
Windows
# esptool installieren (einmalig) pip install esptool # Flashen (Port ggf. anpassen) esptool.py --port COM3 ^ --baud 921600 write_flash ^ 0x0 firmware.bin

Port unter Linux meist /dev/ttyUSB0 oder /dev/ttyACM0 — unter Windows im Gerätemanager nachschauen

11 — Ausblick

Was als Nächstes kommen könnte

OTA-Firmware-Update
Firmware direkt über WLAN auf den Controller flashen — kein USB-Kabel mehr nötig
Fragen-Editor im Admin-Panel
Fragen direkt im Browser erstellen und bearbeiten statt JSON-Datei manuell zu pflegen
Zeitbasierte Punktevergabe
Schnellere Antworten bringen mehr Punkte — Countdown wird auf OLED und Beamer angezeigt
Mehrrundenspiel & Statistiken
Punktestand über mehrere Runden persistent — Auswertung pro Spieler und Frage
